# LangChain POC

This repository is a Python proof-of-concept for retrieval-augmented generation (RAG) using LangChain.

## Code location

- The main example code is in the `notebook/` folder.
- Open `notebook/vector_db_injection_and_retriever.ipynb` to see the full workflow.

## What it includes

- LangChain integration
- Persistent Chroma vector database setup
- Notebook-based text loading, embedding, and retrieval examples
- Example data in `data/` and a local vector store in `data/vector_store/`

## Requirements

See `requirements.txt` for the Python dependencies.
